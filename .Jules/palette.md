## 2024-05-19 - Accessible Modal Design Pattern
**Learning:** React 18's `useId` is perfect for generating dynamic IDs for `aria-labelledby` linking in reusable component layouts like modals, but it requires fallback strings in disconnected environments (like simple NextJS component isolated verification tests) to prevent hydration mismatches. Modal close buttons require explicit `aria-label="Close modal"` and a rounded hover background/`focus-visible` state to ensure keyboard users and screen readers can effectively identify and operate the dismissal action without visual context.
**Action:** Always link a generic `role="dialog"` container to its semantic title using `aria-labelledby` with a unique ID, apply `aria-hidden="true"` to icon SVG children inside interactive elements, and define `focus-visible` ring properties for close/dismissal buttons.
