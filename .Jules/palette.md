## 2025-02-18 - [Add ARIA boundaries to Modal UI Component]
**Learning:** Custom modal components built with pure React/Tailwind need explicit ARIA boundaries (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`) to be recognized by screen readers. Furthermore, the close button needs an `aria-label` when it contains only an icon, and `aria-hidden="true"` should be applied to the SVG itself. Without explicit keyboard focus states (`focus-visible`), keyboard users cannot easily determine when they are focused on the close button.
**Action:** When creating or modifying generic UI modal components, ensure `useId()` is used to link `aria-labelledby` with the title. Always add explicit accessibility attributes, and specifically ensure that icon-only interactive elements have clear `aria-label` tags and proper `focus-visible` styling using Tailwind's ring utilities.
