## 2024-04-01 - Custom Modal Accessibility Boundaries
**Learning:** The custom modal component in this application (`src/components/ui/modal.tsx`) lacks native HTML dialog attributes when used directly as a customized `div`. Explicit ARIA boundaries (`role="dialog"`, `aria-modal="true"`, and `aria-labelledby`) are critically needed to inform screen readers correctly about the modal state and the title connection. The `aria-labelledby` needs an ID that links to the dialog's header, which has to be carefully handled in Next.js to avoid SSR mismatches or React 18 Context issues during static generation.
**Action:** Always verify custom modal/dialog components have `role="dialog"`, `aria-modal="true"`, an appropriate label/labelledby association, and clear ARIA descriptions on icon-only close buttons. Ensure robust ID generation when linking titles.
