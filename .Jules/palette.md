## 2024-04-24 - Accessible Modal Component implementation
**Learning:** When implementing accessibility improvements for modal components in Next.js using React 18, `useId` provides the ideal way to dynamically link a title to `aria-labelledby`. However, when using custom tooling for Playwright verification (like testing bundled isolated components instead of running the app), `useId` can sometimes return undefined or behave unexpectedly due to missing framework context.
**Action:** When using `React.useId()` for accessibility bindings, always provide a fallback value (e.g., `const id = React.useId(); const safeId = id || 'fallback-id'`) to ensure the application remains robust and tests don't break even when the framework's hydration or server-rendering context is absent.
