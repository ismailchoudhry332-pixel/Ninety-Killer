## 2024-05-20 - Accessible Modals & React useId Fallback
**Learning:** Custom modal components in React need explicit ARIA boundaries to be screen reader friendly. However, relying purely on React's `useId()` can be risky if it fails to resolve an ID due to server/client mismatch or framework context.
**Action:** When building custom modals, explicitly add `role="dialog"`, `aria-modal="true"`, and use an `aria-labelledby` linked to the modal's title ID. To safely provide this title ID, utilize a `useId()` call with a fallback string (e.g., `const id = React.useId(); const safeId = id ? \`${id}-title\` : 'modal-title-fallback';`) to ensure robust accessibility linkage and prevent hydration crashes or unlabelled regions. Close buttons also require `aria-label` and `focus-visible` styling, with inner SVGs marked `aria-hidden="true"`.
