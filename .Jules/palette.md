## 2024-04-10 - [Accessibility] Modal Component ARIA Attributes & Focus
**Learning:** The custom `Modal` component in `src/components/ui/modal.tsx` was missing critical ARIA attributes for screen readers to recognize it as a dialog and announce its title. Additionally, the icon-only close button lacked an `aria-label`, leaving it unannounced, and the decorative SVG needed `aria-hidden="true"`. Keyboard navigation was difficult because the focus state was not visible.
**Action:** Implemented the standard dialog pattern: added `role="dialog"`, `aria-modal="true"`, and linked the title using a dynamically generated ID via `React.useId()` for `aria-labelledby`. Added `aria-label="Close modal"` to the close button, `aria-hidden="true"` to the SVG, and explicitly added `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-gray-400 rounded-md` for clear visual feedback during keyboard navigation.
