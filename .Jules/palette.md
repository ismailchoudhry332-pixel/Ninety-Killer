## 2024-04-26 - Custom Modal ARIA Boundaries & React useId Fallbacks
**Learning:** Custom modals missing ARIA boundaries (`role="dialog"`, `aria-modal="true"`, `aria-labelledby`) fail to trap screen reader context properly. When generating unique IDs for `aria-labelledby` with `React.useId()` in environments that might strip the framework context (like esbuild rendering isolated components for visual tests), the hook can return `undefined`, causing accessibility regressions or React errors if left unhandled.
**Action:** Always wrap custom overlay UI elements with appropriate ARIA boundaries, add a fallback for `useId()` (e.g., `const safeId = id || 'fallback-id'`), ensure icon-only buttons include `aria-label` and `aria-hidden="true"` on the SVG, and provide `focus-visible` states to support keyboard navigation.
