## 2024-04-04 - Accessible Custom Modals
**Learning:** Custom modals in Next.js require explicit ARIA boundaries (`role="dialog"`, `aria-modal="true"`) to prevent screen readers from reading background content. The `aria-labelledby` attribute must link to the modal title using a hydration-safe ID generated by React's `useId()` hook to avoid hydration mismatches between server and client. Icon-only close buttons need both an `aria-label` and `focus-visible` styling (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to ensure keyboard navigability.
**Action:** Always implement the `useId()` pattern for custom ARIA IDs and explicitly define ARIA roles and focus states when building or modifying custom interactive components like Modals or Dialogs.
