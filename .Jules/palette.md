## 2024-05-11 - Modal Accessibility Pattern
**Learning:** Found that the standard Modal component in the design system lacked critical ARIA attributes (role='dialog', aria-modal, aria-labelledby) and keyboard focus indicators for the close button. Adding these is crucial for screen reader users and keyboard navigators.
**Action:** When implementing or reviewing future modal or overlay components, ensure they map title IDs correctly using `useId()`, define the dialog role, and explicitly hide decorative icons from screen readers while providing focus states for all interactive elements.
## 2025-02-12 - Sidebar Accessibility Pattern
**Learning:** Found that the main sidebar navigation links lacked critical accessibility attributes (`aria-current="page"`) and keyboard focus indicators (`focus-visible` classes). Furthermore, decorative SVG icons within links were not hidden from screen readers.
**Action:** When implementing or reviewing navigation menus, always ensure the active link uses `aria-current="page"`, add explicit `focus-visible` utility classes for keyboard navigation, and hide purely decorative icons using `aria-hidden="true"` to prevent redundant screen reader announcements.
